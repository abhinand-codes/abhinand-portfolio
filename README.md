# Abhinand PP Portfolio

Premium personal portfolio for Abhinand PP, focused on Laravel, backend APIs, ERP, SaaS, GRC, Vue.js, and enterprise systems.

## Run Locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
